# Contributing

Contributions to FLACblaster are gladly welcome!

In order to get a grasp of how this program works, its goals and its design decisions, take a look at [ARCHITECTURE.md](./ARCHITECTURE.md). Some comments in the code use jargon that can only be understood after reading ARCHITECTURE.md, so please read it. Things that are not documented in the code should be documented in ARCHITECTURE.md, and vice versa. 

## Style
These are the two style conventions:
- Write clean code.
- Don't add line breaks where convention requires it even though it is not necessary. This applies especially to comments and documentation. Use visual line wrapping instead. This can be enabled in Android Studio by pressing Ctrl+E and then Ctrl+W. In VSCode you need to press Ctrl+Z. The rationale is that manual line indentation is a burden and adds extra work.

## AI
Use AI! But use it *responsibly* and review the generated code. Also, instruct your AI agent to ingest the [CLAUDE.md](./CLAUDE.md) file. If this bothers you, feel free to copy this file to your agent's convention file (e.g. GitHub Copilot lays its files into the .github folder)
